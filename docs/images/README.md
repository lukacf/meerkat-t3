# README screenshots

These images show the real MeerkaT3 web interface used by the desktop app, captured
from source revision `8e5f33060f582631e8840f955a6e4f014a968f3d` on October 16, 2026.
The bundled Meerkat Core and Meta version is 0.9.1.

The screenshots use disposable Catalog API and Storefront projects. Their agent
conversations contain scripted demonstration responses from a local model fixture.
They illustrate the interface and workflow, not the quality of a model's completed
work. The proposal reuses an example generated for a synthetic repository study,
loaded into the disposable profile for display. No personal project data, account
credentials, or user profile was used.

- [Workspace](workspace.png): project specialists and a domain conversation.
- [Project specialists](project-specialists.png): reviewing a repository-derived
  specialist proposal before applying assignments.
- [Agent peering](agent-peering.png): connections between specialists in related
  projects.

When updating these images, use a fresh isolated profile and sample repositories,
keep the interface unmodified, and check the entire capture for private content.
