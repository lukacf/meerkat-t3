# Appearance and themes

Open **Settings > Appearance** to choose a theme and follow the system appearance or stay in light or dark mode. To use different themes for light and dark mode, select the corresponding preview within each theme. Appearance preferences are saved on this device.

Use **Change theme** in the command palette to select a theme without leaving the conversation. **Change appearance** chooses System, Light, or Dark independently of the theme. Customize their shortcuts in **Settings > Keybindings**.

## Motion

The sidebar, right panel, and terminal drawer open and close immediately by default. The **Panel animations** setting can add motion, unless reduced motion is enabled in macOS. Moving between threads restores the selected thread's panel state without replaying its transitions.

## Custom themes

Choose **Create theme** to adjust a palette, or import a T3 Code or VS Code theme. The theme editor lets you select an area of the app to find the color to change. Export a theme as JSON to share it.

## Environment themes

The inherited T3 server can supply additional themes and defaults. Server theme publishing is outside the desktop preview workflow; the original `t3` CLI does not configure a packaged MeerkaT3 installation.

### Publish a theme

For this preview, use the theme editor's export and import actions to share a custom theme. This keeps each installation's choice independent.
