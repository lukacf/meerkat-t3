# Open source licenses

Meerkat T3 includes the T3 Code interface, Meerkat and MobKit, and other third-party software and assets. Their license and attribution notices ship with the app.

For interface and JavaScript dependency notices, open **Settings > General**, find **Open source licenses** under **Diagnostics**, and select **View licenses**. Search for a package, version, or license, then expand a row to read its notice text. **Find bundled notices** opens this guide offline.

For the bundled native runtime notices, find the installed Meerkat T3 app in Finder, choose **Show Package Contents**, then open **Contents > Resources > native-notices**. Its `README.txt` explains the collection, and `inventory.json` identifies the components and their notice files. The original T3 Code license is also preserved at **Contents > Resources > LICENSE**.

The **electron-notices** folder beside it contains Electron's license and the full Chromium notices used by the desktop shell and browser. Open `LICENSES.chromium.html` in a browser to read that collection.
