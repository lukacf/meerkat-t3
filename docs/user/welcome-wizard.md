# First-run setup

First-run setup connects your local computer, configures a model account, and opens a project for its long-lived specialists. See [Installation and availability](install.md) before starting. The runtime is bundled; you do not need a previous coding-agent installation or conversation history.

Choose this Mac for the supported preview. Remote installation is outside its scope; installing the original T3 CLI does not install MeerkaT3.

The steps are **Connect**, **Model access**, **Project**, and **Project agents**. After choosing and checking your project, start a repository study, review the proposed specialists, and apply the assignments you want. Choose **Continue to specialists** to open a specialist's conversation and finish setup. Its preparation may still be running. **Skip setup** is available if you want to explore first. Search for **Set up your workspace** to reopen setup when ready.

The specialists stay with the project across tasks. [Start with your project](getting-started.md) explains their assignments and how to connect them within or across projects. Use [Accounts and billing](accounts.md) if you are unsure which credentials to supply. Importing projects from another coding agent is optional; you can open a local folder or clone a repository instead.

Setup saves your place on this device. Reloading the **Project** step restores the selected computer and its project draft without starting a clone or creating a project. Return using the same app or browser profile; a different server address may have separate saved progress.

An unfinished **First task** setup from an earlier build can still resume its saved conversation and finish after a successful reply. You can then generate project specialists from the project's actions menu.

Only complete repository URLs without embedded credentials, query parameters, or fragments are saved. Other URL input remains in the open form but is omitted after reload. Use **Discard draft** to clear the saved form; it does not delete an existing project.

If setup reports a connection or settings error, use Retry after the underlying problem is resolved. If a draft could not be saved, keep the view open until you have preserved the details you need. Do not replace your saved profile with an empty one. For a disconnected agent, uncertain message, or interrupted task, see [Recovery and troubleshooting](troubleshooting.md).
